# Momentia

> **CMS propio para crear experiencias digitales personalizadas y memorables.**

Momentia es una aplicación web desarrollada en **PHP** para crear y gestionar experiencias digitales personalizadas, con especial enfoque en momentos románticos, historias, propuestas y recuerdos.

El proyecto ha evolucionado desde una página web romántica hasta una pequeña plataforma con **instalador, configuración dinámica, administración, API, idiomas y gestión multimedia**.

## ✨ Características

- 🧩 **CMS propio** para gestionar el contenido de la experiencia.
- ⚙️ **Sistema de instalación** mediante asistente web.
- 🗄️ **Configuración y contenido dinámicos** almacenados mediante base de datos.
- 🔐 **Panel de administración** para gestionar el sistema.
- 🌐 **Sistema de idiomas** mediante archivos independientes.
- 🖼️ **Gestión de imágenes y multimedia**.
- 🎵 **Música de fondo** configurable.
- 💌 **Experiencia romántica interactiva** con historia, carta y propuesta.
- 📱 **Diseño responsive** adaptado a dispositivos móviles y escritorio.
- 🔗 **Open Graph y Twitter Cards** para compartir las experiencias en redes y aplicaciones de mensajería.
- 🔌 **API propia** para las operaciones y comunicación del sistema.
- 📤 **Sistema de subida de archivos** para los recursos multimedia.

## 🛠️ Tecnologías

- **PHP**
- **MySQL / MariaDB**
- **HTML5**
- **CSS3**
- **JavaScript**
- **Google Fonts**

## 📁 Estructura

```text
Momentia/
├── admin/              # Panel de administración
├── data/               # Datos y recursos del sistema
├── languages/          # Archivos de idiomas
├── api.php             # API de Momentia
├── config.php          # Configuración y funciones principales
├── index.php           # Experiencia pública
├── install.php         # Instalador
├── upload.php          # Gestión de subidas
└── README.md           # Documentación
```

## 🚀 Instalación

1. Descarga o clona el repositorio.
2. Coloca los archivos en un servidor compatible con PHP.
3. Configura el acceso a la base de datos en `config.php`.
4. Accede al proyecto desde el navegador.
5. Completa el asistente de instalación mediante `install.php`.
6. Una vez instalado, configura la experiencia desde el panel de administración.

> **Nota:** Momentia está pensado para ejecutarse en un entorno PHP con una base de datos MySQL o MariaDB.

## 🎯 Objetivo

Momentia busca proporcionar una base propia para crear experiencias digitales que puedan adaptarse a diferentes ocasiones: **propuestas, aniversarios, historias personales, cumpleaños, recuerdos o cualquier momento especial**.

La idea es mantener una arquitectura sencilla y ampliable, permitiendo que el proyecto pueda evolucionar progresivamente hacia un CMS más completo.
